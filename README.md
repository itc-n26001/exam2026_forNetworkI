# 2026年度期末考査 Network I

## 注意事項

### 試験前

- 学生証と PC の持ち込みだけを許可する
- 机上に学生証を提示せよ
- 試験時間は環境設定終了後の 90 分 とする

### 試験中

- 担当官に指示に従って試験を進めよ
- インターネットの使用は許可する
- 不正行為が発覚した場合は試験を中止の上退室させる
- 試験終了 10 分前に担当官が終了を告げる  

## 試験の流れ

### 環境構築

[試験問題](https://github.com/omas-public/exam2026_forNetworkI.git)を各自の GitHub に Fork &　Clone せよ

### 試験開始

1. 学籍番号名のブランチを作成しそのブランチに移動せよ
2. 上記ブランチにて学籍番号のディレクトリを作成しそこに移動せよ
3. 上記ディレクトリにて [examsheet.md](../examsheet.md) を 学籍番号.md という名称でコピーせよ
4. 学籍番号.md の問題にしたがい，回答を記入せよ
5. 回答が終了したら 学籍番号.md をステージしてコミットせよ
6. `git push origin 学籍番号` を用いて Github に Push せよ
7. 各自のGithub上で該当ブランチの PullRequest を送付せよ

#### note

**学籍番号**は各自の学籍番号を使用するものとする
